3. BACKEND IMPLEMENTATION (FASTAPI + SQLALCHEMY + SQLITE)
--------------------------------------------------------------------------------
Located in: D:\Documents\SEM V\SIH 2026\IMP\backend\

A. Database & ORM Layer:
   - app/config.py: Environment configuration pointing to local SQLite data.db 
     (chosen for zero-setup, portable live jury execution; full PostgreSQL schema.sql 
     maintained for production).
   - app/database.py: SQLAlchemy engine with foreign key pragma enforcement.
   - app/models/schema_models.py: Complete ORM definitions covering Region, State, 
     District, BureauCell, Officer, CanonicalStatus, TrackType, ComplaintCategory, 
     Institution, InstitutionNameVariant, ComplaintCase, CaseText, 
     CaseInstitutionLink, CaseEvent, Relationship, Alert, JointReviewSession, 
     and JointReviewCase. Primary keys adapted to Integer for SQLite autoincrement.
   - app/models/api_schemas.py: Pydantic request/response validation schemas.

B. Core Algorithmic Engines:
   - app/core/entity_resolver.py: 4-tier cascaded resolver. Performs exact PID match, 
     geographic token blocking, acronym dictionary substitution, and Jaro-Winkler 
     similarity scoring via jellyfish. Returns tier and human-review flag.
   - app/core/contradiction.py: ContradictionSentinel scanning cross-bureau status 
     dissonance. Specifically detects when an institution has a DISPOSED case in one 
     bureau while an active inquiry (PENDING/UNDER_PROCESS/ESCALATED) exists in another.
   - app/core/time_travel.py: TimeTravelEngine executing bitemporal state reconstruction. 
     Supports RECORDED (system knowledge) and WORLD (event occurrence) temporal bases. 
     Returns active dockets, milestone events, and whether a conflict was active as 
     of the selected historical timestamp.
   - app/core/sla_engine.py: Evaluates 4 statutory aging buckets (<15d, 15-30d, 
     30-60d, >60d), detects SLA breaches beyond 45 days, and derives next action due.

C. Machine Learning Service:
   - app/ml/ml_service.py: Out-of-the-box local inference engine using Scikit-Learn.
     - TF-IDF + LogisticRegression for 6 complaint categories (Fees, Faculty, 
       Infrastructure, Admission, Examination, Other).
     - Severity keyword heuristic for priority prediction (Low, Medium, High).
     - Cosine text similarity for duplicate detection scoring.
     - Rule-based category-to-bureau jurisdiction mapping.
     - Global singleton pattern pre-trained on realistic seed corpus, ready for 
       immediate drop-in replacement with teammate's trained .pkl model files.

D. REST API Endpoints (All tested & functional):
   - app/api/dashboard.py:
     - GET /api/dashboard/kpis: Real-time aggregated counters.
     - GET /api/dashboard/bureau-workload: Bureau-by-bureau workload and avg disposal days.
   - app/api/cases.py:
     - GET /api/cases: Filtered central case registry with institution profiles.
     - GET /api/cases/{case_id}/events: Chronological audit events for Case Passport.
   - app/api/coordination.py:
     - GET /api/coordination/contradictions: Active contradiction sentinel alerts.
     - GET /api/coordination/overlaps: Coordination Intelligence Layer answering 
       the 3 core questions (Why review together, why might not need, justified action).
     - POST /api/coordination/joint-review: Convenes Inter-Bureau Joint Conference.
     - GET /api/coordination/joint-review: Lists active/resolved conference dockets.
     - PUT /api/coordination/joint-review/{session_id}/resolve: Records signed 
       disposal determination memo and harmonizes dockets.
   - app/api/time_travel.py:
     - GET /api/time-travel/query: Historical state reconstruction with milestones.
   - app/api/entity.py:
     - POST /api/entity/resolve: Tests 4-tier cascade on arbitrary input text.
   - app/api/ml.py:
     - POST /api/ml/infer: Runs categorization, priority, and duplicate check.

E. Seed Data & Launch:
   - app/seed/init_db.py: Pre-seeds 4 institutions (Mepco Schlenk Engineering College,
