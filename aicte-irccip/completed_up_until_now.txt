3. BACKEND IMPLEMENTATION (FASTAPI + SQLALCHEMY + POSTGRESQL/SQLITE READY)
--------------------------------------------------------------------------------
Located in: D:\Documents\SEM V\SIH 2026\IMP\backend\

A. Database & Dual Engine Architecture:
   - app/config.py: Environment configuration reading DATABASE_URL dynamically.
   - app/database.py: Production-ready SQLAlchemy engine supporting both Cloud 
     PostgreSQL (with QueuePool, pool_size=10, pool_pre_ping=True, pool_recycle=1800) 
     and zero-latency local SQLite fallback for offline portable evaluations.
   - deploy_db.py: One-click production database migrator and seeder. Automatically 
     creates schema tables, initializes seed data, and verifies connectivity.
   - render.yaml: Cloud infrastructure-as-code specification for zero-downtime 
     managed deployment on Render / MeghRaj Cloud with PostgreSQL service.

B. Core Algorithmic Engines:
   - app/core/entity_resolver.py: 4-tier cascaded resolver. Performs exact PID match, 
     geographic token blocking, acronym dictionary substitution, and Jaro-Winkler 
     similarity scoring via jellyfish. Returns tier and human-review flag.
   - app/core/contradiction.py: ContradictionSentinel scanning cross-bureau status 
     dissonance. Specifically detects when an institution has a DISPOSED case in one 
     bureau while an active inquiry (PENDING/UNDER_PROCESS/ESCALATED) exists in another.
   - app/core/time_travel.py: TimeTravelEngine executing bitemporal state reconstruction. 
     Supports RECORDED (system knowledge) and WORLD (event occurrence) temporal bases. 
     Returns active dockets, milestone events, and whether a conflict was active as 
     of the selected historical timestamp.
   - app/core/sla_engine.py: Evaluates 4 statutory aging buckets (<15d, 15-30d, 
     30-60d, >60d), detects SLA breaches beyond 45 days, and derives next action due.

C. Trained Machine Learning Integration (Connected from caselink-ml):
   - app/ml/models/complaint_classifier.joblib: Scikit-learn Pipeline (TfidfVectorizer 
     + LogisticRegression) classifying grievance text across 6 regulatory domains 
     (Admission, Examination, Faculty, Fees, Infrastructure, Other).
   - app/ml/models/complaint_priority.joblib: Scikit-learn Pipeline predicting priority 
     levels (High, Medium, Low) coupled with regulatory emergency triggers.
   - app/ml/data/bureau_mapping.csv & duplicate_samples.csv: Statutory mapping files 
     routing grievances to specific bureau cells (e.g. PGRC Student Fees Cell, 
     RB Infrastructure Cell, RB Faculty Affairs Cell).
   - app/ml/ml_service.py: Production-grade MLTextIntelligenceService:
     - Automatically loads trained joblib pipelines on startup.
     - Computes TF-IDF cosine similarity against existing database dockets and 
       duplicate sample corpus (threshold >= 0.70 flags probable duplication).
     - Provides sub-80ms real-time inference on POST /api/ml/infer.
     - Directly integrated into POST /api/intake/webhook for real-time AI auto-triage.

D. REST API Endpoints:
   - app/api/dashboard.py:
     - GET /api/dashboard/kpis: Real-time aggregated counters.
     - GET /api/dashboard/bureau-workload: Bureau-by-bureau workload and avg disposal days.
   - app/api/cases.py:
     - GET /api/cases: Filtered central case registry with institution profiles.
     - GET /api/cases/{case_id}/events: Chronological audit events for Case Passport.
   - app/api/coordination.py:
     - GET /api/coordination/contradictions: Active contradiction sentinel alerts.
     - GET /api/coordination/overlaps: Coordination Intelligence Layer answering 
       the 3 core questions (Why review together, why might not need, justified action).
     - POST /api/coordination/joint-review: Convenes Inter-Bureau Joint Conference.
     - GET /api/coordination/joint-review: Lists active/resolved conference dockets.
     - PUT /api/coordination/joint-review/{session_id}/resolve: Records signed 
       disposal determination memo and harmonizes dockets.
   - app/api/intake.py:
     - POST /api/intake/webhook: Real-time complaint ingestion with DPDP HMAC-SHA256 
       salt tokenization, 4-tier PID resolution, and AI auto-triage classification.
     - GET /api/intake/status: Gateway operational status.
   - app/api/time_travel.py:
     - GET /api/time-travel/query: Historical state reconstruction with milestones.
   - app/api/entity.py:
     - POST /api/entity/resolve: Tests 4-tier cascade on arbitrary input text.
   - app/api/ml.py:
     - POST /api/ml/infer: Serves trained Scikit-learn model inference.
